# Madhav Food Caters + Madhav Villas

## Structure
- `index.html` — complete single-page website
- `styles.css` — responsive premium design
- `script.js` — menu category cards, filtering, lightbox and WhatsApp room enquiry
- `assets/restaurant-hero.jpg` — restaurant photo supplied in this chat
- `assets/` — existing Madhav Villas room/bathroom images from the previous website

## Important: add your Zomato link
Open `index.html` and replace:
`YOUR_ZOMATO_LINK_HERE`
with the real Zomato restaurant URL.

## Add restaurant photos
The restaurant gallery has four slots. Replace the slot blocks in `index.html` with `<img>` elements pointing to your four additional restaurant photos.

## Add menu photos and names
The menu is deliberately data-driven in `script.js`. Replace the placeholder dish cards with your actual dish names, prices and image paths once the final menu/photos are supplied. Do not publish invented prices.
